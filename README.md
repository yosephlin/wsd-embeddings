# Word Sense Disambiguation using Embeddings (PA5)

This project implements and compares two machine learning models for Word Sense Disambiguation (WSD) on the word "line", distinguishing between the 'phone' and 'product' senses. It utilizes pre-trained GloVe word embeddings as features, moving beyond traditional bag-of-words approaches.

This was developed for Programming Assignment 5.

## Features

The core feature representation relies on **GloVe word embeddings**. For each instance of the word "line":
1.  The surrounding context words are extracted.
2.  The pre-trained GloVe vector for each context word (present in the GloVe vocabulary) is retrieved.
3.  These vectors are **averaged** to create a single, dense feature vector representing the semantic context of that instance.
4.  Instances where no context words are found in the GloVe vocabulary are represented by a zero vector.

## Models Implemented

Two classification models are implemented:

1.  **Support Vector Machine (SVM):**
    * Implemented using `scikit-learn`'s `SVC`.
    * Finds an optimal hyperplane (boundary) in the high-dimensional embedding feature space to separate the 'phone' and 'product' senses.
    * This implementation uses a linear kernel (`kernel='linear'`).

2.  **Neural Network (NN):**
    * Implemented using `PyTorch`.
    * A simple feed-forward neural network (Multi-Layer Perceptron) with one hidden layer and ReLU activation.
    * Architecture: Input Layer (embedding dimension) -> Hidden Layer (e.g., 64 neurons) -> ReLU -> Output Layer (2 neurons for 'phone'/'product').
    * Trained using `Adam` optimizer and `CrossEntropyLoss`. Learns potentially non-linear patterns in the embedding features.

## Files in the Repository

* `wsd-embeddings.py`: The main Python script that loads data, extracts features, trains the selected model (SVM or NN), predicts senses, and writes the output file.
* `scorer.py`: A Python utility script to evaluate the predictions against the gold standard key. Calculates accuracy and generates a confusion matrix.
* `line-train.txt`: Training data containing instances of "line" with context and marked senses ('phone'/'product'). (Provided by instructor)
* `line-test.txt`: Test data containing instances of "line" with context but *without* sense labels. (Provided by instructor)
* `line-key.txt`: Gold standard key containing the correct senses for the instances in `line-test.txt`. (Provided by instructor)
* `my-line-answers.txt`: Example output file generated by `wsd-embeddings.py` (this file will be created/overwritten when you run the main script).
* `requirements.txt` (Recommended): A file listing the required Python packages.
* `README.md`: This file.

## Setup / Requirements

1.  **Python:** Python `3.11` is required.
2.  **Libraries:** Install the necessary libraries. You can usually install them using pip:
    ```bash
    pip install -r requirements.txt
    ```
    Or individually:
    ```bash
    pip install numpy lxml scikit-learn torch
    ```
    (Ensure your PyTorch version matches the assignment requirement, e.g., `torch==2.2.2`)
3.  **GloVe Embeddings:**
    * Download pre-trained GloVe embeddings from the Stanford NLP website: [https://nlp.stanford.edu/projects/glove/](https://nlp.stanford.edu/projects/glove/)
    * This project was developed/tested using `glove.6B.100d.txt` (6 Billion token, 100-dimensional vectors), but other versions might work. Place the downloaded `.txt` file in your project directory or provide the correct path when running the script.
4.  **Data Files:** Ensure `line-train.txt`, `line-test.txt`, and `line-key.txt` are in the same directory as the scripts, or provide the correct paths. These files are typically provided in a `line-data.zip` archive.

## Usage

1.  **Run the WSD Model:**
    Execute `wsd-embeddings.py` from your terminal, providing the paths to the train, test, and embedding files, and optionally specifying the model ('SVM' or 'NN'). The script will write its output directly to `my-line-answers.txt`.

    * **Using SVM (Default):**
        ```bash
        python wsd-embeddings.py line-train.txt line-test.txt path/to/glove.6B.100d.txt SVM
        ```
        *(Or omit `SVM` as it's the default)*

    * **Using Neural Network:**
        ```bash
        python wsd-embeddings.py line-train.txt line-test.txt path/to/glove.6B.100d.txt NN
        ```
    *(Replace `path/to/glove.6B.100d.txt` with the actual path to your GloVe file)*

2.  **Evaluate the Results:**
    Run the `scorer.py` script, providing the output file generated in the previous step and the gold standard key file.

    ```bash
    python scorer.py my-line-answers.txt line-key.txt
    ```
    *(Use `python3` if `python` defaults to Python 2 on your system)*

    The scorer will print the accuracy and confusion matrix to the console.
